Exclude attachments, redact likely account/card identifiers and reject credential or full-message content before persistence. | Diagnostic error codes · T49.1–T49.2 | Use a closed enum derived only from stable parser outcomes. ## One consolidated HMD Crest session

1. Prepare the APK, fixtures, disposable backend and exact controls on the emulator first. Once the test profile and method are approved, identify the intended phone and record its active profile, app locale, font scale, TalkBack and networking settings. Verify the existing test profile, device authorization, app signing compatibility and disposable account before installing or opening FINORA.
   Android shares installed package code across profiles. A user-targeted install can still replace that code. Run with the identical already-installed binary or obtain approval for a distinct test application ID and associated test build. Stop before replacing the personal profile's binary.
2. In the test profile, complete automated checks first. Stage a protected financial screen, protect its screenshot and Recents preview, force-stop and relaunch, rotate if available, verify expired-session return to sign-in, and remove then restore the temporary route to verify explicit recovery. Run approved device-only instrumentation once. Record sanitized results apart from the automated emulator run.
3. Use one TalkBack activation for both languages. At standard and larger text, inspect Sign in, Language, More → Help, FAQ headings, the financial screen and explicit Retry. Verify wrap/clipping, reading order, Back focus, and spoken error/recovery feedback. Ask the tester for each exact spoken label or missing item. Group English first and Sinhala second before ending TalkBack. Extend this checklist to ticket and diagnostic controls only after their implementations are ready.
4. Sign out the disposable session. Restore the original locale, font, accessibility and profile state, remove only the test mapping, and read back the final state. Store sanitized command summaries and blocked-capture evidence. Retain gaps and do not substitute emulator evidence for handset evidence.
